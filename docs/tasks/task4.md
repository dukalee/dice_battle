## 구현 기능 목록
- 원본 PNG(`assets/characters/<Character>/<character>_<pose>.png`, 1254x1254)에서 게임용 WebP(약 600px, 투명도 유지)를 만드는 변환 스크립트 (`npm run assets:build` 등). 원본은 수정하지 않는다.
- 변환 결과를 `public/` 아래에 두고, 누락된 포즈가 있으면 스크립트와 테스트가 실패하도록 검증한다. (전사 6종, 도적 6종, 마법사 7종 = 19장)
- 포즈 보정 JSON: 캐릭터와 포즈마다 표시 크기 배율, 기준점(몸통 중심, 이미지 비율 x, y), 원본이 향하는 방향(`left`/`right`)을 적는다. 원본 방향은 전사와 도적 모두 `left`이고, `mage_attack`만 `right`이다.
- 스프라이트 로더 (이미지 사전 로딩, 로딩 완료 대기)
- 스프라이트 그리기 함수: 캐릭터, 포즈, 몸통 기준 좌표, 보고 싶은 방향을 받아 보정값을 적용해 그린다. 플레이어는 화면 오른쪽을 보도록(왼쪽에 서 있으므로) 뒤집고, AI는 왼쪽을 보도록 그리며, 포즈별 원본 방향 값으로 뒤집을지를 정한다.
- 개발용 스프라이트 확인 화면: 3명의 캐릭터를 좌우 배치로 놓고 포즈를 바꿔 가며 크기와 기준점이 맞는지 눈으로 확인한다. (개발 중에만 접근)
- 보정값 튜닝: 포즈를 바꿔도 캐릭터 몸집(머리 크기)과 몸통 위치가 크게 튀지 않도록 JSON 값을 조정한다. (`critical_*`처럼 이펙트가 큰 포즈는 이펙트가 화면을 넘지 않는 범위에서 맞춘다.)
