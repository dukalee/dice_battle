## 구현 기능 목록
- Pause: 상단 중앙의 Pause 버튼이 주사위 굴림, 연출, AI 턴 중에도 언제든 동작한다. 일시정지하면 게임 루프의 dt를 0으로 막아 주사위, 포즈 전환, 문구, AI 지연 등 모든 연출이 그 자리에서 멈추고, 렌더는 유지한다.
- Pause 메뉴: 이어하기(멈춘 지점부터 계속, 이미 정해진 눈금은 바뀌지 않음), 재시작(캐릭터 선택 화면으로), 타이틀 이동. Pause 중에는 공격/회복/주사위 입력이 막힌다.
- GAME OVER 화면: 도달한 ROUND 표시, 재시작(캐릭터 선택 화면으로), 타이틀 이동 버튼
- 상태 초기화: 재시작이나 타이틀 이동 시 배틀 상태, 연출 타이머, 로그, 입력 잠금 상태를 모두 초기화하고, 다음 게임에 이전 상태가 남지 않게 한다.
- 전체 점검: PRD 수용 기준 전체를 확인하고, 규칙 엔진의 단위 테스트와 화면 흐름을 맞춰 본다. 한국어 문구와 레이아웃 겹침을 확인한다.
- 성능 확인: 도적 추가 굴림(주사위 4개)과 `critical_*` 이펙트 포즈가 겹치는 상황에서도 60fps에 가깝게 유지되는지 확인한다.
- `CLAUDE.md`의 아키텍처 항목 갱신: 디렉터리 구조, 규칙 엔진/배틀/연출/화면의 역할과 데이터 흐름, 주요 명령

## 검증 기록

### 브라우저 (Chrome 154, Edge 154, Firefox 157, 모두 헤드리스, 같은 시나리오)
세 브라우저에서 모두 같은 결과였고 콘솔 오류는 없었다.
- 타이틀 → 설명서 → 돌아가기 → 캐릭터 선택 → 전사로 게임 진입.
- 주사위가 굴러가는 도중 Pause: 루프와 장면이 모두 멈추고(`paused`), 1.5초 동안 주사위 위치가 그대로였다. 멈춘 동안 공격/회복/주사위 영역을 눌러도 `busy` 상태 그대로였다. 이어하기 후 계속 진행됐다.
- AI 턴 중(주사위가 자동으로 굴러가는 도중) Pause: 1.5초 동안 그대로였고 이어하기 후 AI 턴이 끝까지 진행됐으며 눈금은 바뀌지 않았다.
- Pause 메뉴 "재시작" → 캐릭터 선택 화면, 루프는 멈춰 있지 않았다. 새로 시작한 게임: ROUND 1, HP 최대, 적 HP 최대, 로그 1줄, 주사위 영역 숨김, 내 차례. Pause 메뉴 "타이틀" → 초기 화면, 루프는 멈춰 있지 않았다.
- 마법사 한 판(시드 5)을 실제 던지기로 GAME OVER까지 진행: "ROUND 1 까지 진행했습니다", 재시작 → 캐릭터 선택. 마법사 1,1,1(시드 507) → GAME OVER, 타이틀 → 초기 화면.
- 한국어 문구와 레이아웃은 세 브라우저의 일시정지 메뉴와 GAME OVER 화면 캡처로 확인했다.
