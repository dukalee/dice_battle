# Task 5: 화면 전환 기반과 초기 / 설명서 / 캐릭터 선택 화면

## 참조
- PRD FR-15 (캐릭터 선택 후 ROUND 1 시작), FR-22 (초기 화면, 설명서), FR-23 (캐릭터 선택 화면)
- PRD 비기능: Pointer Events 입력, UI 문구 한국어
- PRD 사용자 흐름 1~3

## 선행 task
- Task 1 (캔버스, 논리 좌표 변환, 게임 루프)
- Task 2 (캐릭터 정의 데이터)
- Task 4 (스프라이트 그리기)

## 구현 기능 목록
- 화면(Scene) 관리자: 초기 / 설명서 / 캐릭터 선택 / 게임 / GAME OVER 화면을 전환하고, 각 화면이 update, render, 입력 처리를 가진다. (게임, GAME OVER 화면의 내용은 Task 6~9)
- Pointer Events 입력 모듈: 눌림, 이동, 뗌을 논리 좌표로 변환해 현재 화면에 전달한다. 마우스와 터치를 같은 경로로 처리한다.
- 캔버스 버튼 컴포넌트: 영역, 라벨, hover/pressed/disabled 상태, 클릭 이벤트
- 한국어 문구가 깨지지 않도록 폰트 스택과 텍스트 줄바꿈/가운데 정렬 유틸
- 초기 화면: "Dice Battle" 타이틀, 게임 시작 버튼, 설명서 버튼
- 설명서 화면: 게임 진행 방법과 3종 캐릭터 규칙(최대 HP, 주사위 수, 공격/회복 조건)을 스크롤 없이 한 화면에 요약하고, 초기 화면으로 돌아오는 버튼
- 캐릭터 선택 화면: 캐릭터별 색을 가진 세로 카드 3장(전사 / 도적 / 마법사). 각 카드에 이름, `idle` 스프라이트, 스탯(최대 HP 게이지, 주사위 개수), 한 줄 소개, 공격/회복 규칙 줄을 표시한다. 별도 선택 버튼은 없고 카드 전체가 버튼이다. (이후 참고 이미지에 맞춰 카드형으로 개편) 선택하면 선택한 캐릭터 정보를 가지고 게임 화면으로 넘어간다.

## 완성 조건
- [x] 초기 화면에서 게임 시작 버튼을 누르면 캐릭터 선택 화면으로, 설명서 버튼을 누르면 설명서 화면으로 이동한다.
- [x] 설명서 화면의 모든 내용이 스크롤 없이 한 화면에 들어가고, 돌아가기 버튼이 동작한다.
- [x] 캐릭터 선택 화면이 세 영역으로 나뉘고, 각 영역에 최대 HP, 주사위 개수, 규칙 요약이 표시된다.
- [x] 영역을 클릭하면 해당 캐릭터로 게임 화면에 진입한다.
- [x] 창 크기를 바꿔도 버튼의 클릭 위치와 보이는 위치가 일치한다.
- [x] 마우스와 터치(Pointer Events) 입력 모두 버튼이 동작한다.
- [x] hover와 pressed 상태가 시각적으로 구분된다.
- [x] `npm run test`와 `npm run build`가 통과한다.
