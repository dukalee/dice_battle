# Task 6: 게임 화면 레이아웃과 배틀 연결

## 참조
- PRD FR-24 (좌측 플레이어, 우측 AI, 상단 HP 바, ROUND 표시), FR-28 (로그 창), FR-1 (공격/회복 선택), FR-16~FR-18 (적 선정, 턴 순서)
- PRD 사용자 흐름 3~4
- PRD 수용 기준: 새 ROUND에서 적 HP 최대치, 플레이어 턴으로 시작

## 선행 task
- Task 3 (배틀 진행 로직)
- Task 4 (스프라이트 그리기)
- Task 5 (화면 관리자, 버튼 컴포넌트)

## 구현 기능 목록
- 게임 화면 레이아웃: 좌측에 플레이어 캐릭터, 우측에 AI 캐릭터를 `idle` 포즈로 배치하고 화면 중앙에 캐릭터가 보이게 한다.
- 최상단 좌우에 HP 바 (현재 HP / 최대 HP 수치 포함). HP가 바뀌면 바가 부드럽게 줄고 늘어난다.
- 현재 ROUND 번호 표시
- 상단 중앙의 Pause 버튼 자리 (동작은 Task 9)
- 하단의 공격 / 회복 버튼. 플레이어 턴이 아니거나 연출 중에는 비활성화 상태로 표시한다.
- 로그 창: 최근 메시지를 아래로 쌓아 보여주고, 넘치면 오래된 줄을 밀어낸다. 메시지 추가 함수를 제공한다. (메시지 내용은 Task 8에서 채운다.)
- 배틀 로직 연결: 게임 화면에 진입하면 선택한 캐릭터로 ROUND 1을 시작하고, 3종 중 랜덤으로 적을 정해 배치한다. 라운드가 바뀌면 적 스프라이트와 HP 바를 갱신한다.
- 임시 연결(확인용): 공격/회복 버튼을 누르면 주사위 연출 없이 즉시 결과를 적용하고, HP 바와 로그에 반영한다. (Task 7, 8에서 실제 흐름으로 교체)

## 완성 조건

- [x] 상단 좌우 HP 바에 두 캐릭터의 HP가 정확히 표시되고, HP가 변하면 바와 수치가 갱신된다.
- [x] ROUND 번호가 표시되고, 라운드를 클리어하면 증가한다.

- [x] 로그 창에 메시지가 쌓이고, 넘치면 오래된 줄이 사라진다.
