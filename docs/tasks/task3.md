# Task 3: 배틀 진행 로직 (턴, 라운드, 종료 판정)

## 참조
- PRD FR-3 (HP 범위, 최대 HP에서 회복 허용), FR-14 (마법사 자폭 처리)
- PRD FR-15~FR-20 (캐릭터 선택, 적 선정, 턴 순서, 라운드 클리어 회복, GAME OVER)
- PRD 수용 기준: 최대 HP 회복, 라운드 클리어 회복(도적 35), GAME OVER 전환, AI 마법사 자폭, 새 ROUND 시작 상태

## 선행 task
- Task 2 (캐릭터 데이터, 규칙 함수, RNG)

## 구현 기능 목록
- 배틀 상태 모델: 플레이어/적 캐릭터와 현재 HP, 현재 ROUND, 현재 턴(플레이어/AI), 진행 단계(행동 선택 대기 / 굴림 / 결과 적용 / 라운드 종료 / 게임 오버)
- HP 적용 함수: 데미지와 회복을 적용하고 HP를 0 이상 최대 HP 이하로 제한한다. 최대 HP에서 회복해도 오류 없이 턴만 소모된다.
- 턴 진행: 플레이어 행동 선택 → 규칙 엔진으로 결과 계산 → 적용 → AI 턴(공격/회복을 랜덤 선택) → 적용 → 다음 턴. 항상 플레이어가 먼저 시작한다.
- 결과를 UI가 소비할 수 있는 이벤트 목록으로 반환 (예: `rolled`, `damaged`, `healed`, `selfKO`, `roundCleared`, `gameOver`). 연출 타이밍은 이 모듈이 알지 못한다.
- 적 선정: 매 ROUND마다 3종 중 균등 확률로 랜덤 선정 (플레이어와 같은 종류 가능), 적 HP는 항상 최대치로 시작하고 라운드에 따른 강화는 없다.
- 종료 판정: 적 HP 0 → 라운드 클리어, 플레이어 HP 0 → 게임 오버. 마법사 1,1,1 자폭은 자폭한 쪽의 HP를 0으로 만들어 같은 판정으로 처리한다. (플레이어 자폭 = 게임 오버, AI 자폭 = 라운드 클리어)
- 라운드 클리어 처리: ROUND 증가, 플레이어가 `floor(최대 HP / 2)`만큼 회복(최대 HP 초과 불가), 새 적 선정
- 게임 오버 정보: 도달한 ROUND
- 새 게임/재시작을 위한 초기화 함수
